## EXERCISE

A company that provides energy consulting services helps small neighborhood businesses identify high electricity consumption.

During a visit, basic information about each business and four weekly electricity consumption measurements are recorded.

The program must organize the data, calculate simple indicators, and detect businesses that should receive an energy-saving recommendation.

## DATA STRUCTURE

Each business must be represented by a DICTIONARY and all businesses must be stored inside a LIST.

Each business dictionary must contain exactly these main attributes:

* nit: Business identifier.
* nombre: Business name.
* tipo: Tienda, Restaurante, or Peluquería.
* empleados: Number of employees.
* meta_semanal: Maximum weekly consumption target in kWh.
* consumos: A list containing exactly 4 weekly consumption measurements.

The structure must therefore be:

A list
→ contains dictionaries
→ each dictionary represents one business
→ the "consumos" key contains a list with 4 values.

## EXACTLY 6 MAIN FUNCTIONS

The program must contain EXACTLY these six main functions:

1. registrar_comercios()
2. registrar_consumos(comercios)
3. calcular_promedio(consumos)
4. calcular_variacion(consumos)
5. clasificar_consumo(promedio, meta, variacion)
6. generar_informe(comercios)

Do not create additional main functions.

## 1. registrar_comercios()

This function must register exactly 10 businesses.

For every business, request:

* NIT
* Nombre
* Tipo
* Número de empleados
* Meta semanal de consumo

The "tipo" should correspond to one of:

* Tienda
* Restaurante
* Peluquería

Each business must be represented as a dictionary and its "consumos" value must initially be an empty list.

The function must return the list containing the 10 businesses.

Validate numeric inputs appropriately so the program does not crash if the user enters invalid numeric data.

## 2. registrar_consumos(comercios)

For every business, request exactly 4 weekly electricity consumption values.

Every consumption must be greater than 0.

If the user enters 0, a negative number, or invalid text, ask again.

Store the four values in the "consumos" list of the corresponding business dictionary.

Return the updated list of businesses.

## 3. calcular_promedio(consumos)

Calculate the average of the four consumption measurements MANUALLY.

Requirements:

* Use a loop.
* Use an accumulator.
* Do NOT use sum().
* Do NOT use any equivalent function.

Return the calculated average.

## 4. calcular_variacion(consumos)

Calculate the percentage variation between the first and fourth week using exactly this formula:

((semana4 - semana1) / semana1) * 100

Return the percentage variation.

The first measurement is the first element of the consumption list and the fourth measurement is the fourth element.

## 5. clasificar_consumo(promedio, meta, variacion)

Classify each business according to these rules:

### Eficiente

When:

promedio <= meta

AND

variacion <= 5%

### En observación

When:

promedio <= meta

AND

variacion > 5%

### Alto

When:

promedio > meta

AND

the average does not exceed the meta by more than 20%.

In other words, the average is greater than the meta but less than or equal to meta * 1.20.

### Crítico

When:

the average exceeds the meta by more than 20%.

The function must return the corresponding classification as a string.

Use the previously created functions:

Display for each business:
